Viewing notes

Jack Pope hands this portion of the keynote to Tan for the React Compiler 1.0 release. Her example uses a full name that can be calculated during rendering. Putting it into state through an effect pays for another render, and the new linter can flag that cost. Tan separates adopting the diagnostics from rolling out the optimizer. An existing application can learn from the warnings while its team decides where to enable compilation first.
