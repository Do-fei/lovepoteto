見どころと解説

ソルトレイクシティでの講演は、実行時に発覚する JavaScript のエラーからジェネリクスに進み、関数を入力と出力の対応として描く。全域関数と部分関数の比較で一度止めて、自分の API が扱えない入力を一つ当てはめてみたい。その結果を呼び出し側が予見できるようにするには、シグネチャで何を示せばよいだろうか。最後の GraphQL の章では、同じ問いをネットワーク越しにやり取りするデータの形について考える。
