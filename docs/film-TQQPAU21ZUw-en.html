Data Fetching with React Server Components

▶

Viewing notes

Dan Abramov sets up a design problem: bring data requirements close to the component that uses them while keeping downloads small and interactions responsive. Tan takes over for the notes-app demonstration. Follow a single selection between the editor, the running application and the browser tools. That gives a concrete way to ask where data is read, what is sent across the network, and which part of the interface still needs client-side state.
