見どころと解説

FindMyPast と Pinterest の開発者が、Lauren を含む React チームに設計の疑問をぶつける。アプリ内のデータを一つ思い浮かべて聴くとよい。誰がそのデータを取得し、どこでキャッシュできるのか。次のページを読み込むときやリクエストが失敗したとき、その責任はどう変わるのか。最後の導入に関する議論では、こうした問いが既存アプリの段階的な移行につながる。Server Components がまだ研究段階にあった頃、利用する側が何を見極めようとしていたのかが伝わる。
