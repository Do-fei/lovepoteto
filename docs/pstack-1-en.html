Give the agent a path through the app

The Complete Guide to pstack Pt. 1

Where to begin

Tan invents a desktop app called Atlas to show what a verification tool can do. Starting a conversation, sending a message, waiting for the interface to settle and inspecting its accessibility tree form a path to an observable result.

A closer look

A feature map supplies the knowledge that a button-clicking tool lacks: how a user reaches a feature and what they should see there. Our reading is that the map belongs alongside the product because a navigation change can invalidate an otherwise working test.

What should the screenshot settle?

The Atlas example includes a way to wait for the interface to settle. A screenshot captured while a response is streaming can change between runs. Our reading is that a verification tool needs to describe the conditions of observation. The action, the wait and the capture together make the result interpretable.
