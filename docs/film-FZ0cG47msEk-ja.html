見どころと解説

React チームの4人による基調講演。Lauren のパートでは、すでに本番で動いているアプリが React 18 へ移行する道筋を考える。「並行モード」という呼び名から、一つずつ採用できる「機能」へと言葉が変わるところに注目したい。チームはまず基盤を更新し、並行レンダリングを活かす操作を後から選べる。ワーキンググループを通じて、ライブラリやアプリを保守する側が、リリース前の段階で移行にかかる労力や実際にぶつかる難しさを開発チームに伝えられた。
