見どころと解説

複数の登壇者が担当する基調講演で、Jack Pope から引き継いだ Lauren が React Compiler 1.0 を発表する。例に挙がるのは、レンダー中に姓と名から組み立てられるフルネームだ。Effect を使ってそれを state に書き込めば、レンダーが余計に一回発生する。新しい lint ルールはその無駄を指摘できる。診断機能とコンパイラによる最適化は別々に導入できるので、既存のアプリでもまず警告を読み、どこからコンパイルを有効にするかはチームで決められる。
