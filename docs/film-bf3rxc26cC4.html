演讲精读

这场多人主旨演讲里，Jack Pope 把舞台交给 Lauren，由她发布 React Compiler 1.0。留意她举的姓名字段：本可在渲染时算出的值，如果经由 Effect 再写回状态，就多走了一轮渲染。她把编译器、能独立启用的 lint 规则和既有应用的渐进迁移串成一条采用路径，团队可以先找出问题，再决定哪部分上线优化。
