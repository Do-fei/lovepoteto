Confessions of an Ember Addon Author

▶

Viewing notes

Start with the few lines a person would need to use an addon. Tan uses documentation-driven development to bring that interface into focus, then shows how a build hook can strip unused helpers from the delivered app. Compatibility changes the standard of proof again. A package that runs on the maintainer’s machine must also survive the Ember versions and browsers its users actually have.
