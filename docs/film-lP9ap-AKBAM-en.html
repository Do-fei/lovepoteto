2016 · EmberConf

Idiomatic Ember: Sweet Spot of Performance and Productivity

▶

Viewing notes

When someone edits an input, which object should change the data? Tan’s examination of two-way bindings gives that question a concrete shape. Actions and services offer different ways to move a change through an Ember application. Later she compares computed properties, helpers and component hooks. Trace a single edit back to the object that owns the value, then notice how many other components only need to display it.
