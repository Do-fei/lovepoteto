当工程经理开始带一组 Agent

How I Use Cursor

从哪里读起

Lauren 写新人入职时有一个细节：一个会写代码的人，仍然需要了解这个团队怎样排查问题、怎样判断工作已完成。Agent 还有一个额外困难，它在新会话里可能连昨天已经走过的弯路都不知道。

再看一个细节

她以滚动位置周期性漂移为例，把复现、提出假设、缩小范围和修复后验证串起来。pstack 把这种调查方式留给下一个会话。并行也有明确用途：几条独立调查可以集中回答同一个难题。

Benny 为什么先开工单

她的维护机器人 Benny 先向反馈者补问复现条件，再查代码、历史记录和已有讨论，把调查结果写进工单。另一个步骤才尝试复现和修复。这个分工保留了一个很实际的出口：看似异常的界面也许正是产品当初设计的样子。

编者手记

值得记录的一条团队经验，应当能告诉后来的人下一步要看哪个信号。比如「空闲时记录滚动位置」就能帮助一个新会话重新进入现场。
