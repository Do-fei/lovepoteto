Coding is dead, long live Coding

読む手がかり

高校生のとき、ローレンは HTML の marquee タグを見つけた。自分の書いたもので画面の文字が動く。手を動かした結果が、その場で目に見えた。コードを一行ずつ磨くのがなぜあんなに楽しかったのか、その仕事の形が変わる今、何を失ったと感じるのか。どちらの気持ちも、この記憶からたどることができる。

具体例を読み解く

話はやがて、以前は自分の手に余ったアイデアに移る。いまも、それを形にするには、どんなものを作りたいかを思い描き、エージェントが理解できるだけの背景を渡す必要がある。題名の後半で再び大文字の C から始まる Coding には、手の動かし方が変わっても、ソフトウェアを作る喜びのどの部分を残したいか、という問いも読み取れる。

靴職人が登場する理由

靴職人のたとえが示すのは、技は受け継がれても、多くの人の日常からは遠のくことがある、ということだ。ローレンはそこから、いま使える言語やフレームワーク、モデルを支えている先人たちの仕事に目を向ける。だからこそ結びの言葉にも重みがある。初めて作る人の喜びと、長く作ってきた人が手仕事を懐かしむ気持ちは両立する。

編集ノート

ローレンの検証についての文章と併せて読みたい。本当に作りたい小さなものを選び、満足のいく出来になったと何を見て判断するかを書いてみる。二つの文章は、この練習の前半と後半をそれぞれ照らしてくれる。
