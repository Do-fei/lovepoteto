第一次让文字动起来的快乐

Coding is dead, long live Coding

从哪里读起

Lauren 从高中发现 HTML 的 marquee 标签写起。屏幕上的字动了起来，这种立刻看见自己改变了什么的快乐，解释了她为什么愿意花时间琢磨每一行代码，也解释了手写过程被替代时真实的失落。

再看一个细节

文章随后把目光放到以前做不出来的东西上。她仍然得先形成一个清晰的设想，再找到足够的上下文把它传递给 Agent。标题里大写的第二个 Coding，可以读作一个开放的问题：当手上的动作发生变化，创作的哪一部分还值得保留？

为什么她会提到鞋匠

文中借用鞋匠的比喻，承认一种手艺可以继续存在，却逐渐退出大多数人的日常。Lauren 随后提醒读者，今天的模型、语言和框架都继承了前人的劳动。这个转折让结尾的乐观更有分量：新一代人更容易参与创造，和老程序员怀念手感，两件事可以同时为真。

编者手记

这篇适合与她的验证文章配对阅读。先选一个你真想做出来的小东西，再写下你会如何认出它已经足够好。两篇文章分别照亮了这个练习的两半。
