Before the agent writes its first line

deepcoding

Where to begin

A rough destination can be enough for an exploratory prototype. In a mature product, however, the first example an agent finds can influence a whole patch. Tan uses deepcoding for a change in the order of work: put the evidence that should shape the implementation in front of the model while the design is still open.

A closer look

Her example is a React codebase full of old components that misuse useEffect. A search through nearby files can make technical debt look like a house convention. A smaller, representative example may be more informative than the full result set. Someone still has to know why that example deserves the model’s attention.

How she makes preparation affordable

Her Claude Code plugin used separate searches for documents, changes and discussions, then asked questions to fill the gaps. The main task received a selection of relevant material. Preparing that selection costs time, which helps explain why Tan leaves space for quick prototypes when even the person commissioning the work is still exploring.

Editor’s notebook

Take a change that needed rework. Find the instruction that arrived too late, pair it with a relevant file or test, and move both to the beginning. Observe which decision changes.
