React 18 Keynote

Viewing notes

Four React team members share this keynote. Tan’s segment asks what upgrading would look like for an application already in production. Watch the terminology shift from a concurrent mode to individually adoptable features. A team can upgrade the foundation, then decide which interactions warrant new behavior. The working group matters in that account because people maintaining libraries and applications can surface the costs of migration while the release is still taking shape.
