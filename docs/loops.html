一枚早餐鸡蛋与软件交付的瓶颈

Loops You Can Trust

从哪里读起

早餐店得同时端出鸡蛋、吐司和咖啡。煮蛋需要三分钟，无论吐司机有多快，整份早餐都有一道绕不过去的工序。Lauren 借 Andy Grove 的例子问：在 Agent 写软件的流程里，哪一步让后面所有工作都得等？

再看一个细节

她在 Cursor 的性能排查里找到了一个答案。Agent 得能启动开发版、重现用户遇到的操作、记录性能，再于改动后重测。让它接触到工程师判断问题时使用的信号，才有条件把人工排查变成可重复的流程。

一次像素对齐的迁移，仍然漏掉了什么

她把共享 UI 库迁到 StyleX 时，采样画面看起来一致，内部试用却发现了层叠顺序和全局样式依赖的问题。下一轮每次只迁一个叶子组件，删除样式前先查谁还在使用它。这个改动既缩小了影响范围，也让失败更容易追溯到一个具体选择。

编者手记

如果一次重测没有重现原始问题，这次结果该写成「证据不足」。让流程能在这里停下来，是放心把下一次任务交给它的前提。
