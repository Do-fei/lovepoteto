演讲精读

Lauren 在这场多人主旨演讲里负责回顾 React 社区。她先给出 npm 下载规模，再用开发者调查切换视角：有多少人在学编程时用到了 React？紧接着，数字换成贡献者的面孔和社区活动的画面。三个镜头合在一起才能读懂这段演讲。下载量描述软件传播的一面，教程、聚会和人们动手做出的库则解释它如何被传下去。
