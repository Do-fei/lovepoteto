Viewing notes

In Austin, Tan shows a template iterating over a list and later opens up a sorting helper. Watch what becomes visible at each level: the template expresses which order the list should have, while a small function holds the comparison that implements it. The toggle example then asks a similar question about interaction. How much of a state change can a clear name communicate to the next reader?
